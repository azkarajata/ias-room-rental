# IAS Room Rental — GitHub Pages

Website dummy untuk portal sewa ruangan Gedung Lini 2 Terminal Kargo Bandara Internasional Soekarno-Hatta, bernuansa InJourney Aviation Services.

## Fitur
- Login Customer dan Admin
- Dashboard
- Daftar 6 ruangan dummy
- Pengajuan booking oleh customer
- Riwayat pemesanan customer
- Approval/rejection booking oleh admin
- Data booking disimpan di `localStorage`

## Akun demo
- Customer: `customer` / `customer123`
- Admin: `admin` / `admin123`

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `ias-room-rental`.
2. Upload `index.html`, `app.html`, `style.css`, `app.js`, dan folder `assets`.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/root`, lalu Save.
6. Tunggu proses deployment dan buka URL GitHub Pages yang diberikan.

> Catatan: login pada versi ini adalah **demo frontend**, bukan autentikasi produksi. Username/password dapat dilihat di JavaScript. Untuk website perusahaan yang benar-benar digunakan, gunakan backend/authentication dan database.
